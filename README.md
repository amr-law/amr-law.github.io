# Сайт-резюме Шбаира Амира Анвара

Статический сайт, полностью готовый для GitHub Pages.

## Файлы
- `index.html` — разметка сайта
- `styles.css` — стили
- `script.js` — навигация и анимации
- `assets/` — изображения, PDF резюме и научных работ

## Публикация на GitHub Pages
1. Создайте репозиторий (например `amir-law-site`).
2. Загрузите **содержимое этой папки** в корень репозитория.
3. Откройте `Settings` → `Pages`.
4. В разделе `Build and deployment` выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`.
6. Сохраните настройки.

Сайт не требует npm, сборки или серверной части.

Обновление v6: в карточке AI-инструментов оставлен только Google Gemini, кнопка «Наверх» переведена на JavaScript smooth scroll.

## Mobile adaptation
The desktop layout is unchanged. Additional responsive rules are applied only below 900px, with a dedicated phone layout below 620px. The layout includes iPhone safe-area support, Android/iOS navigation behavior, touch-sized controls, and responsive cards/content.
